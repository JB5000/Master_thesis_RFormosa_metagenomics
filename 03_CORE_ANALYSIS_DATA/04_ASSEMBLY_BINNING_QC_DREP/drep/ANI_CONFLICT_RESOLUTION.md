# dRep parameters

The final MAG29 dRep run used dRep 3.6.2 with 56 input genomes, `-comp 90`,
`-con 5`, `-l 50000`, primary ANI `-pa 0.9`, secondary ANI `-sa 0.95`,
`-nc 0.1` and `--S_algorithm fastANI`.

The retained `Cdb.csv` records a secondary clustering distance of 0.05
(ANI 0.95), and `Wdb.csv` records 29 representatives.
